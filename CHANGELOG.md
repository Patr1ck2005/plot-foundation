# Changelog

## 0.1.12

- Added an Agent guardrail linking plot specifications and renderers to the
  canonical intrinsic-data-dimension and sampling-topology decision process.
- Characterized that a single x-first 2D scalar grid can validly feed both a
  heatmap spec and a 3D surface spec without changing orientation.
- Kept all public models and renderer APIs unchanged.
- Included Agent/docs/test sources in the sdist and modernized MIT SPDX
  metadata for clean public builds.

## 0.1.11

- Published the domain-neutral artist, specification, and scoped style APIs.
- Kept axes ownership, output paths, and physical interpretation with callers.

Earlier internal development history is intentionally not part of the public
release branch.
